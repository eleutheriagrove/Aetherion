## Overview

Aetherion is an open, minimal, fully reproducible computational toy model that implements the 10D/11D tensor resonance framework described in the accompanying academic paper. It demonstrates predictive world-modelling, explicit cross-modal qualia-like binding, sparse foveal attention, meta-compute self-awareness, and a strict ethical goal hierarchy.

## Features

- Exact 11D qualia binding with fully explicit bilinear term \(\mathbf{Q}(\mathbf{e}_t)\)
- Sparse foveal attention ("one thing at a time")
- Multi-modal + internal + meta-compute residues
- Signed qualia valence (pleasure/pain) driving curiosity
- Goal hierarchy (protect human life → self-preservation → uncertainty reduction)
- Fully reproducible with fixed random seeds
